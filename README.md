# TEKZ-AUTO-NEWS

بوت Python ينشر أخبار التقنية والذكاء الاصطناعي بالعربية في وجهة Telegram المحددة. يقرأ مصادر RSS، يمنع إعادة نشر الخبر نفسه باستخدام SQLite، ويعيد صياغة الخبر عبر OpenRouter مع صورة وأزرار للاشتراك والمشاركة والنقاش. يظهر رابط المتابعة بدل رابط المصدر في نص المنشور، بينما يبقى رابط الخبر الأصلي في زر المشاركة وقاعدة البيانات.

## الإعداد على Replit

1. أنشئ بوتًا عبر BotFather، ثم أضفه إلى وجهة النشر كمسؤول مع صلاحية نشر الرسائل.
2. أضف `OPENROUTER_API_KEY` و`TELEGRAM_BOT_TOKEN` و`TELEGRAM_CHANNEL_URL` و`TELEGRAM_GROUP_URL` إلى **Secrets** في Replit. لا تضع مفاتيح API أو رمز البوت في ملفات المشروع أو المحادثة.
3. أضف `TELEGRAM_CHAT_ID` كمتغير بيئة عادي: اسم الوجهة العام مثل `@my_channel` أو رابطها العام مثل `https://t.me/my_channel` أو المعرّف الرقمي مثل `-1001234567890`.
4. شغّل `python main.py`. يتحقق البوت من حسابه وصلاحياته، ثم يفحص الموجزات ويكرر الفحص كل 15 دقيقة.

يمكن استخدام متغيرات الإعداد الإضافية الموجودة في `.env.example`. يقرأ التطبيق `.env` محليًا للتطوير، لكن لا تضع ملف `.env` أو أي مفاتيح داخله في Git أو في ملف `.env.example`.
ينشر البوت خبرًا واحدًا كحد أقصى في كل دورة. يبدأ التشغيل بفحص فوري؛ استخدم `python main.py --defer-first-cycle` لتأجيل أول فحص إلى موعد الدورة التالية.

## تشغيل مستمر 24/7

سير العمل في Replit يبقى نشطًا ما دام قيد التشغيل. للتشغيل المستمر حتى عند إغلاق المحرر، انشر المشروع كـ **Reserved VM** (آلة افتراضية مستمرة)، واجعل أمر التشغيل `python main.py`. لا تستخدم Autoscale أو Scheduled لهذا البوت: فهو عامل خلفية دائم، وليس موقعًا يعتمد على الطلبات أو مهمة مجدولة قصيرة.

تظل القناة بحاجة إلى أن يكون البوت مسؤولًا. لا ينشر التطبيق إلا بعد نجاح إعادة الصياغة وتنزيل صورة صالحة وإرسالها إلى Telegram. إذا تعذر ذلك، يسجل الخطأ ويحاول مجددًا في دورة لاحقة.
إذا انتهى رصيد OpenRouter، يوقف البوت طلبات المزود لمدة ست ساعات لتجنّب تكرار الأخطاء؛ أضف رصيد API وأعد تشغيل سير العمل لاستئناف النشر فورًا.
إذا رفض Telegram النشر بسبب الصلاحيات أو كان البوت محذوفًا من الوجهة، يوقف البوت النشر حتى تُصلح العضوية أو صلاحية النشر ثم تعيد تشغيل سير العمل.

## النشر والتكرار

- عدّل `rss_sources.json` لإضافة أو حذف مصادر RSS موثوقة.
- يقبل البوت الأخبار المنشورة خلال آخر 72 ساعة افتراضيًا، ويرتبها حسب الحداثة والموضوع، مع أولوية أخبار الذكاء الاصطناعي وإطلاق المنتجات.
- يحفظ رابط الخبر ومحاولات النشر ووقت النشر ومعرّف رسالة Telegram في `data/tekz_auto_news.db`. لا تحذف قاعدة البيانات إذا أردت الاحتفاظ بسجل منع التكرار.
- تُستخدم صورة الخبر من RSS أولًا، ثم صورة Open Graph، ثم صورة تقنية بديلة عند عدم وجود صورة مناسبة.
- يضم كل منشور أزرارًا للاشتراك والمشاركة والنقاش. يظهر رابط المتابعة `https://linktr.ee/loversincere29` بدل رابط المصدر في النص.
- قد ينشر البوت استطلاعًا واحدًا خلال 24 ساعة إذا كان الخبر عن إطلاق منتج مناسب؛ تُحفظ أعداد الأصوات ونتائج الخيارات.
- أوامر المشرفين في وجهة النشر: `/status` و`/now` و`/stats` و`/help`. يتطلب `/now` فحصًا فوريًا وينشر خبرًا واحدًا كحد أقصى.
- تيليجرام يتحكم بحجم الخط في التطبيق؛ يبرز البوت العنوان والافتتاحية بالخط العريض ويستخدم فقرات قصيرة لتحسين القراءة.

## أوامر المشرفين

- `/status` — يعرض حالة البوت وآخر وقت نشر.
- `/now` — يطلب فحصًا فوريًا، مع حد أقصى خبر واحد.
- `/stats` — يعرض عدد الأخبار والمحاولات والاستطلاعات والأصوات.
- `/help` — يعرض قائمة الأوامر.

## تشغيل محلي

```bash
python -m pip install -r requirements.txt
cp .env.example .env
python main.py
```

أدخل القيم محليًا في `.env` فقط، ولا تشارك الملف. في Replit، استخدم Secrets للمفاتيح.
