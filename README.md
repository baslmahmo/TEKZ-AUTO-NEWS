# TEKZ-AUTO-NEWS

بوت Python ينشر أخبار التقنية والذكاء الاصطناعي بالعربية في قناة Telegram. يقرأ مصادر RSS، يمنع إعادة نشر الخبر نفسه باستخدام SQLite، ويعيد صياغة الخبر عبر OpenAI مع إسناد رابط المصدر وإرفاق صورة من الموجز أو صفحة الخبر.

## الإعداد على Replit

1. أنشئ بوتًا عبر BotFather، ثم أضفه إلى قناتك كمسؤول مع صلاحية نشر الرسائل.
2. أضف `OPENAI_API_KEY` و`TELEGRAM_BOT_TOKEN` إلى **Secrets** في Replit. لا تضعهما في ملفات المشروع أو المحادثة.
3. أضف `TELEGRAM_CHAT_ID` كمتغير بيئة عادي: اسم القناة العام مثل `@my_channel` أو رابطها العام مثل `https://t.me/my_channel` أو المعرّف الرقمي للقناة الخاصة مثل `-1001234567890`.
4. شغّل `python main.py`. سيتحقق البوت من اتصال Telegram، ثم يفحص الموجزات فورًا ويكرر الفحص كل 15 دقيقة.

يمكن استخدام متغيرات الإعداد الإضافية الموجودة في `.env.example`. يقرأ التطبيق `.env` محليًا للتطوير، لكن لا تضع ملف `.env` أو أي مفاتيح داخله في Git أو في ملف `.env.example`.
في أول تشغيل، ينشر البوت أحدث ثلاثة أخبار كحد أقصى ويتجاهل العناصر الأقدم من موجزات RSS حتى لا يغرق القناة بمنشورات قديمة.

## تشغيل مستمر 24/7

سير العمل في Replit يبقى نشطًا ما دام قيد التشغيل. للتشغيل المستمر حتى عند إغلاق المحرر، انشر المشروع كـ **Reserved VM** (آلة افتراضية مستمرة)، واجعل أمر التشغيل `python main.py`. لا تستخدم Autoscale أو Scheduled لهذا البوت: فهو عامل خلفية دائم، وليس موقعًا يعتمد على الطلبات أو مهمة مجدولة قصيرة.

تظل القناة بحاجة إلى أن يكون البوت مسؤولًا. لا ينشر التطبيق إلا بعد نجاح إعادة الصياغة وتنزيل صورة صالحة وإرسالها إلى Telegram. إذا تعذر ذلك، يسجل الخطأ ويحاول مجددًا في دورة لاحقة.
إذا انتهى رصيد OpenAI، يوقف البوت طلبات OpenAI لمدة ست ساعات لتجنّب تكرار الأخطاء؛ أضف رصيد API وأعد تشغيل سير العمل لاستئناف النشر فورًا.

## مصادر الأخبار والتكرار

- عدّل `rss_sources.json` لإضافة أو حذف مصادر RSS موثوقة.
- يقبل البوت الأخبار المنشورة خلال آخر 72 ساعة افتراضيًا، وبحد أقصى خمسة منشورات في كل دورة.
- يحفظ الروابط والعناوين وحالة النشر في `data/tekz_auto_news.db`. لا تحذف قاعدة البيانات إذا أردت الاحتفاظ بسجل منع التكرار.
- تُستخدم صورة الخبر من RSS أولًا، ثم صورة Open Graph، ثم صورة تقنية بديلة عند عدم وجود صورة مناسبة.

## تشغيل محلي

```bash
python -m pip install -r requirements.txt
cp .env.example .env
python main.py
```

أدخل القيم محليًا في `.env` فقط، ولا تشارك الملف. في Replit، استخدم Secrets للمفاتيح.
